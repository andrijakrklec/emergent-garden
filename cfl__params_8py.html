Detailed Description

Clustered-federated-learning (IFCA) tunables for the simulation.

These parameters are used in particle.py: cluster-count bounds, split/merge thresholds, the non-IID bias structure, migration hysteresis, the behavioral / obstacle forces, the local<->global blend schedule, and the emergent-pull weight.
